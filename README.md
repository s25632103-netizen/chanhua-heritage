# 纏花文化｜傳承與創新（網站初版）

## 本機預覽
1. 解壓縮資料夾。
2. 以 Chrome、Edge 或 Safari 開啟 `index.html`。
3. 搜尋、分類篩選、導覽及文獻外連已可操作。

## 免費發布：GitHub Pages
1. 登入 https://github.com/ 並建立一個新的 Public repository（例如 `chanhua-heritage`）。
2. 將 `index.html` 上傳到 repository 根目錄。
3. 進入 repository 的 Settings → Pages。
4. 在 Build and deployment 選擇 `Deploy from a branch`。
5. Branch 選 `main`、資料夾選 `/ (root)`，按 Save。
6. 等待部署完成，GitHub 會提供公開網址，格式通常為 `https://你的帳號.github.io/chanhua-heritage/`。

## 上線前必做
- 將作品圖鑑中的符號示意圖替換成自行拍攝、取得授權或明確開放授權的真實照片。
- 補上圖片作者、來源、授權方式及拍攝/典藏資訊。
- 請教師確認研究範圍、文獻格式與內容深度。
- 目前沒有會員、資料庫或後台；若要多人新增資料，需再擴充。

## 目前功能
- 響應式版面（手機/平板/電腦）
- 頁面導覽
- 圖鑑關鍵字搜尋與分類篩選
- 官方及學術資料外連
- 靜態網站，可免費部署於 GitHub Pages
